# 🚨 Intelligent Emergency Response Platform

## SIH Hackathon Project

The Intelligent Emergency Response Platform is a smart web-based emergency management system designed to help users report emergencies and enable emergency response teams to prioritize and manage incidents efficiently.

## Features

- Emergency reporting
- Emergency type classification
- Intelligent priority detection
- Critical / High / Medium classification
- Emergency response dashboard
- Emergency status management
- SQLite database
- Flask REST API
- Responsive web interface

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Python
- Flask
- Flask-CORS

### Database

- SQLite
